# Лабораторная работа №10 — голосовой ассистент, вариант 1

Ассистент работает с [Dog CEO API](https://dog.ceo/dog-api/) и распознаёт команды:

- `следующая` — получает новую случайную картинку;
- `показать` — открывает текущую картинку в браузере;
- `сохранить` — сохраняет её в папку `downloads`;
- `назвать породу` — извлекает породу из ссылки;
- `разрешение` — сообщает ширину и высоту картинки;
- `помощь`, `выход` — служебные команды.

Обрабатываются неизвестная команда, сетевые ошибки, неверный ответ API, ошибка картинки,
отсутствие голосовых библиотек и модели.

## Быстрая проверка без микрофона

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py --text
```

## Голосовой режим

1. Установите голосовые зависимости:

   ```powershell
   python -m pip install -r requirements-voice.txt
   ```

2. Скачайте небольшую русскую модель с <https://alphacephei.com/vosk/models>,
   распакуйте и переименуйте её папку в `model` рядом с `main.py`.
3. Подключите микрофон и выполните:

   ```powershell
   python main.py
   ```

Можно оставить исходное имя модели и передать `--model путь_к_модели`.
