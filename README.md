# Лабораторные работы №7–10

Готовые решения для варианта 1:

- `lab-7-weather` — погода через OpenWeatherMap;
- `lab-8-opencv` — перевод изображения в оттенки серого и отслеживание метки;
- `lab-9-flask` — веб-приложение «Заметки» на Flask и SQLite;
- `lab-10-assistant` — голосовой ассистент для Dog CEO API.

Каждая папка — самостоятельный проект со своим `README.md`, зависимостями и тестами.
API-ключ OpenWeatherMap намеренно не записан в файлы: перед запуском его нужно передать
через переменную окружения либо ввести в скрытом интерактивном запросе.
