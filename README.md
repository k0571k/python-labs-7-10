# Лабораторные работы №7–10

- `lab-7-weather` — погода через OpenWeatherMap;
- `lab-8-opencv` — перевод изображения в оттенки серого и отслеживание метки;
- `lab-9-flask` — приложение «Заметки» на Flask и SQLite;
- `lab-10-assistant` — голосовой ассистент для Dog CEO API.

 В каждой папке есть отдельный `README.md`, который определяет зависимости, так же присутствует документ с необходимым перечнем библиотек, которые надо импортировать для работы кода
